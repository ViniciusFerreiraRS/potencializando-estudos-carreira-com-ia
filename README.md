# Plano de estudos de 30 dias — Desenvolvimento de software e automação

Este repositório registra uma atividade prática do curso **Potencializando Estudos e Carreira com IA**, da DIO, adaptada aos meus objetivos de transição para a área de tecnologia.

## Objetivo

Construir uma base prática em desenvolvimento de software e automação, avançando em lógica de programação, fundamentos de Java, Git e GitHub, banco de dados e APIs.

O plano considera minha experiência profissional anterior em vendas, produção e logística e meus estudos atuais no IFRS e na DIO.

## Tópicos de estudo

1. **Lógica de programação:** variáveis, operadores, condições, repetições e funções.
2. **Fundamentos de Java:** sintaxe básica, tipos de dados, decisões e laços.
3. **Git e GitHub:** versionamento, commits e documentação de projetos.
4. **Banco de dados e SQL:** tabelas, consultas e operações básicas.
5. **APIs e automação:** comunicação entre sistemas e automação de tarefas.

Ao longo do plano, pretendo registrar conteúdos estudados, exercícios realizados, dúvidas, dificuldades, pequenas entregas práticas e próximos passos.

**Importante:** este é um plano de estudo pessoal e flexível. A prioridade é compreender os fundamentos e praticar, não apenas concluir aulas ou acumular certificados.
